# MIDI Reader 使用说明（试用版 0.1）

双击 `MIDI Reader.exe` 打开，把 MIDI 文件拖进窗口（或点左上角“打开”）。也可以直接把 MIDI 拖到 exe 图标上。

**原 MIDI 一个字节都不会改。** 你的整理结果存在旁边的 `xxx.mid.reader.json` 里，下次打开自动套用。想从头来，删掉这个文件即可。

## 界面

- **右边：总谱式多轨视图**。一行一个声部，按乐器组排好，所有行共用一条时间轴。
  - 点组标题（▼ 弦乐）折叠成一条概览带，再点展开
  - 红色音符：超出这件乐器的演奏极限；黄色：超出舒适音域，或者规则拿不准、等你确认
  - 被判成 keyswitch 的音默认不画；工具栏勾“显示 keyswitch”可以用灰色看到它们
  - 鼠标停在音符上：音名、力度、第几小节、为什么标色、原始音符编号
  - 双击一行：用完整钢琴窗打开细看（只读）
  - 行头右边的 **M / S**：静音、独奏。可以同时独奏几条；Ctrl+点击 S 只听这一条。不出声的声部画淡
- **左上：声部列表**。右键一条声部可以改名、指定乐器、合并、拆出、挪来源、上下移、静音、独奏、只听这一条
- **左下：规则结论**。自动清洗做了什么、哪些拿不准。点一条，右边会跳到那里并闪一下
  - “待确认”的默认没生效：点“确认”生效，点“否决”就当没这回事，也不再标黄
  - “已自动”的已经生效：觉得不对就点“否决”
  - 确认或否决过的会一直保留；点“撤回”交还给自动判断

## 操作

| 操作 | 效果 |
|---|---|
| 滚轮 | 上下翻声部 |
| Ctrl + 滚轮 | 以鼠标位置为中心缩放时间 |
| Shift + 滚轮、触控板横向滑动 | 左右平移 |
| 按住左键或中键拖 | 平移 |
| 点标尺 | 跳到那个位置 |
| M / S | 静音 / 独奏选中的声部（Ctrl+S 只听这一条） |
| 空格 / Enter | 播放 / 暂停 |
| Home | 回到开头 |
| F | 看全曲 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做（声部整理、确认否决、逐音修正） |
| Ctrl+O | 打开文件 |
| 右键一个音符 | 标成 keyswitch / 不是 keyswitch（单个，或这条声部里同音高的全部） |

## 整理声部

“声部”是界面上看的单位，和原始轨道分开：

- **几条轨合成一个声部**（比如按演奏法拆开的弦乐）：在左边按住 Ctrl 选几条，右键“合并”
- **一条轨拆成几个声部**：同一轨里不同通道会自动按通道拆开；没把握的会出现在“待确认”里
- **轨道放错了声部**：右键“拆出一个来源”或“把一个来源挪到别的声部”
- **乐器认错了或没认出来**：右键“指定乐器”。指定后音域标色和八度判断会按新乐器重算
- **想推倒重来**：工具栏“重新整理…”按规则重建声部（你确认/否决过的结论和逐音修正会保留）

## 扒谱：把音频变成 MIDI（试验中）

工具栏“扒谱…”，或者直接把音频（wav / mp3 / flac / ogg / m4a / aiff）拖进窗口，会弹出一个对话框：

- **做什么**：直接扒成 MIDI；或者先用 Suno 翻唱成别的风格，再扒
- **编制预设**：流行乐队（人声 / 吉他 / 键盘 / 贝斯 / 鼓）、弦乐四重奏、双管编制管弦乐队。扒完按预设给声部命名、定乐器、排顺序
- **扒谱方式**：默认按预设；也可以换成 MuScriptor 全曲扒、Demucs 分轨后逐轨扒，或者交给 Suno（每次调用都扣点数）
- 对话框下半部分会列出这样扒要用到哪些模型、缺什么。缺的没补上，“开始”是灰的

点“开始”后窗口底部出现任务条：当前步骤、模型的最新输出、用时；能取消。扒好了自动打开，和普通 MIDI 一样看、听、整理。结果放在音频旁边的 `曲名.wav.pipeline\时间-…\` 文件夹里，再打开里面的 `.mid` 就行。同一首用同样的设置再扒，会直接用缓存。

**第一次用之前要准备（一次性）：**

1. 扒谱模型在 Python 那边跑，阅读器要用仓库里的 `proto` 文件夹：先运行一次 `proto\setup.bat`。如果 exe 不在仓库里，对话框会让你选一下仓库（或 proto）文件夹
2. 装 uv（三个本地模型靠它装环境）：PowerShell 里运行 `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`，装完重新打开阅读器
3. 对话框里点“打开配置文件”，填上：
   - `muscriptor.hfToken`：MuScriptor 的权重要先去 huggingface.co/MuScriptor/muscriptor-medium 同意许可，再建一个 read token 填这里
   - `sunoapi.apiKey`：只用 Suno 时才要
4. 回到对话框点“重新检查”

第一次扒会下载几个 GB 的模型环境和权重，要等一阵。出错时点任务条或报错框里的“看日志”，把日志发我。

## 已知的不足（不用反馈这些）

- 播放是参考音色，不讲究；没有声卡时右上角会提示，其他功能照常
- 静音和独奏只在这次打开期间有效，不会记下来
- 整理声部靠右键菜单，还不能拖来拖去
- 职能标签（旋律/和声/低音/律动）、移调显示、鼓谱视图都还没做
- 扒出来的 MIDI 还在用给 DAW 导出的 MIDI 写的规则：会有误报的 keyswitch、八度判断，先否决掉就行
- 一个声部整体错了八度、但刚好全在乐器音域里时，规则看不出来
- 只读：不能改音符

## 用两天后怎么反馈

最有用的是**具体的文件 + 具体的地方**。每条反馈尽量包括：

1. **哪个 MIDI**：把 `xxx.mid` 和旁边的 `xxx.mid.reader.json` 一起发我（后者记着你做过的整理，我能完全复现你看到的画面）
2. **哪里**：声部名 + 第几小节；或者鼠标停在音符上，把提示里的“原始音符 #编号”告诉我
3. **看到什么、本来应该是什么**：比如“Violins 1 第 12 小节这几个低音被当成 keyswitch 藏起来了，其实是旋律”
4. 截图更好

不用管问题属于哪一块。大致对应关系是这样，我按这个定位：

| 你看到的 | 多半出在 |
|---|---|
| 某个音被藏了/没藏、标黄标得莫名其妙 | keyswitch 规则 |
| 一整条声部被升降了八度，或者该升降没升降 | 八度规则 |
| 不该拆的轨被拆开了 / 该拆的没拆 | 按通道拆轨规则 |
| 乐器认错、声部排序怪 | 乐器库（轨名关键词、音域） |
| 画面卡、显示错位、点了没反应 | 画布 |
| 播放不对、光标不跟 | 播放和速度换算 |
| 打不开某个文件、音符数不对 | 读文件 |
